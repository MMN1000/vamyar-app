بسته آماده انتشار PWA وام‌یار

محتویات: index.html (نسخه برنامه)، manifest.webmanifest، sw.js و آیکون‌ها.

مراحل: کل محتویات این پوشه را بدون تغییر ساختار روی یک هاست HTTPS قرار دهید. سپس آدرس index.html را در Chrome اندروید باز کنید و از منو گزینه Install app / افزودن به صفحه اصلی را انتخاب کنید.

برای تبدیل به APK با روش TWA، پس از انتشار باید دامنه اختصاصی/آدرس HTTPS پایدار و فایل assetlinks.json مرتبط با امضای اپ پیکربندی شود و پروژه اندروید با ابزار Bubblewrap یا Android Studio ساخته شود.

توجه: فایل‌های خارجی که برنامه از CDN دریافت می‌کند، در اولین اجرا به اینترنت نیاز دارند؛ عملکرد کاملاً آفلاین باید روی گوشی آزمایش شود. این بسته APK نیست.
